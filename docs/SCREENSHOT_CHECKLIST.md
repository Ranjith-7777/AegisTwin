# Submission Screenshot Checklist

Capture only genuine rendered states:

- Overview during staged playback
- Live Telemetry
- Current Anomaly Assessment
- Incident Candidate
- Observed MITRE timeline
- Predictive Analytics
- Full Digital Twin with distinct layers
- Response Centre rankings
- Simulation-agent workflow
- Human approval gate
- Applied synthetic execution overlay
- Verification result
- Valid Audit Chain result

Before capture, hide local usernames, filesystem paths, development tabs, machine-specific information, accidental credentials, and unrelated applications. Keep the simulation-safety banner visible. Do not fabricate, composite, or relabel screenshots.
