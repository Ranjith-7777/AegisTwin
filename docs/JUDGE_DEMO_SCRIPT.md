# Judge Demonstration Script

This 5-8 minute sequence is entirely synthetic and computes every result live.

1. **0-1 min:** Point out the persistent safety banner and Judge Demo Guide.
2. **1-2 min:** Start `staged-compromise-demo`; explain that normal activity appears first.
3. **2-3 min:** Show the first deviation assessment and evidence-gated MITRE observation.
4. **3-4 min:** Show Incident Candidates and Predicted Hypotheses; distinguish evidence from ranked hypotheses.
5. **4-5 min:** Show Digital Twin; solid activity is observed and dashed activity is hypothetical.
6. **5-6 min:** Generate Response Recommendations and compare cloned-topology impact.
7. **6-7 min:** Create agentic orchestration and explicitly record simulated human approval.
8. **7-8 min:** Execute only in the synthetic twin, verify, roll back, then verify the audit chain.

Backup material must be introduced as: “Backup demonstration evidence from a previously completed synthetic run.” It is never silently substituted for the live workflow.
